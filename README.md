# pairwise-surround-downmix

5.1 片源在立体声耳机里，对白被音乐盖住，爆炸声又只剩左耳：下混按固定系数把中置声道平分到左右，没有按相位和延迟对齐；LFE 直接加到主声道，低频过载削波；环绕声的声道顺序按 WAV 默认，和片源实际布局不一致；中置声道没有优先保留，对白被左右声道抵消；下混后没有做 true peak 限制，峰值溢出；设备只支持单声道时仍按立体声系数下混，能量翻倍；不同片源是 5.1、7.1、Atmos，共用一套矩阵；元数据里的对白归一化没读，音轨增益错；采样率切换后延迟补偿没重算，左右声道相位差；下混在频域做，瞬态被抹平；多轨视频只下混主轨，评论轨没处理；耳机空间化在下混之后做，声像又被拉宽；缓存按视频 ID，换音轨后仍用旧矩阵。media/surround_downmix.py 是核心，tests/test_surround_downmix.py 15个红。要修的是：相位对齐；LFE 衰减；布局识别；中置优先；true peak；单声道系数；多布局矩阵；对白元数据；采样率延迟；时域处理；多轨处理；空间化顺序；缓存版本。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
